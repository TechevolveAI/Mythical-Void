# Private Trumptopus source

`source-original.png` is Kevin's supplied full-body reference, copied unchanged.
No new image generation, replacement character or invented surface pixels.

The source is used only by the private cutout-rig proof. It is not imported by
the production game. `source-foreground.png` is a local Apple Vision extraction,
not regenerated character art. Authored anatomy contours and pivots in
`TrumptopusCutoutData.js` divide that extraction into ten parts. The original
file remains intact. The Apple extraction tool is an offline preparation step,
not a dependency loaded by the browser or a service called for each player.

The first colour-key experiment damaged blue-lit body pixels and was rejected.
Its diagnostic captures remain private; it is not the current implementation.
