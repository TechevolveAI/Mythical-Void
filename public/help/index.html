CONTROLS

Move first. The game teaches the rest.

You do not need to memorise every button. Prompts change when you enter a realm or stand near something you can use.

WASD

Move

Use W, A, S and D—or the arrow keys—to move your creature around the world.

SPACE

Interact

Stand near a glowing marker, person, object or portal and press Space when the prompt appears.

SPACE · W · ↑

Jump

During realm adventures, use Space, W or the Up arrow to jump. The game shows battle controls when you need them.

TAP

Touch screen

Use the movement and action controls shown on the game screen. Turning a phone sideways gives the game more room.

KEEP YOUR PROGRESS

Your first save lives in this browser.

Mythical Void saves locally by default. Return using the same browser and device to continue.

What could make my local save disappear?

Clearing site data, using a private or incognito window, or moving to another browser or device can remove or hide it. If you want to keep your current progress, do not clear browser data while trying to fix the game.

Do I need Cloud Save?

No. Cloud Save is optional. It can keep a copy of game progress using an anonymous game account, but it is not needed to begin. Younger players should ask a parent or guardian before turning it on.

Can I begin again?

The game has options that can change saved progress. Read any warning carefully and ask a grown-up if you are unsure. A reset cannot be undone unless a separate usable save exists.

IF SOMETHING ISN’T WORKING

Try the safe fixes first.

Stop when the game works again. Avoid deleting browser data if the progress in this browser matters to you.

  1. 01
    Reload once

    Wait a moment, then reload the game page. Repeated reloading will not make a slow connection faster.

  2. 02
    Check the browser

    Use an up-to-date version of Chrome, Edge, Firefox or Safari. The game needs JavaScript and WebGL.

  3. 03
    Give the game some room

    Close other busy games or video tabs. On a phone or tablet, close unused apps and turn the screen sideways.

  4. 04
    Check the connection

    Some parts need the internet. If the connection has dropped, reconnect and reload once.

Please don’t send personal information.

A staffed Mythical Void help inbox is not open yet, and this page has no contact form. If anything feels upsetting, unsafe or confusing, close the game and tell a parent, guardian or another trusted adult.

QUICK ANSWERS

Things players often wonder.

What am I trying to do?

Recover Wanderer-77, hatch and care for a creature, cross six realms, clear the corruption holding their guardians, build a sanctuary and decide what Project Beacon should become.

Why does my creature look different in another picture?

The pixel creature is the trusted game form. Some optional “living” pictures are creative interpretations of the same saved traits, and marketing artwork can imagine the wider universe. Those images are not screenshots of gameplay.

Is Mythical Void multiplayer?

No. It is a single-player game. The Hatch Challenge lets two people hatch separately and compare results, but it does not connect the players or upload their creatures.

Where can a grown-up learn more?

The family guide explains cost, accounts, saves, fantasy combat, privacy and how AI is used.
