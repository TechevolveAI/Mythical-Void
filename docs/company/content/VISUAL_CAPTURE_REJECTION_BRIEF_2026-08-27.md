# Gameplay visual brief — post-visibility review

The latest production build was captured privately on phone and desktop after the new visible-story work landed. The code now proves that the creature, choice, memory and movement states exist. The pictures still do not make those moments feel clear, beautiful or exciting to a new player.

Nothing from this run should be placed on the website, sent to Kevin for approval, posted on social media or supplied to a distribution partner.

## What the next game pass must change

### 1. Make helping physical

Place one blocked route or danger in the foreground. The creature should perform one large, recognisable action and visibly change that obstacle. Do not rely on a text panel, thin beam or `+5` label to explain what happened.

### 2. Make choices transform the world

The choice can be short and readable, but the marketing moment is the consequence after the menu closes. Change a large part of the playable scene: dead ground becomes alive, a current starts moving, a structure unfolds, weather clears, or creature behaviour changes. The result must be obvious with all copy removed.

### 3. Create one impossible alien event

The current memory scene looks like targeting lines over a settlement. Build a phenomenon that feels native to another dimension: liquid memory climbing upward, folded light creating a route, migrating geometry, gravity growing roots, or a living current that visibly carries remembered shapes. Keep the astronaut and creature in the frame reacting to it.

### 4. Stage a real traversal route

The movement clips contain 138 technically valid frames, but almost every frame is the same empty dark route. Capture six to ten seconds with layered terrain, parallax, moving environmental life, at least one jump or obstacle and continuous creature movement. Avoid clipped platforms and dead space.

## Release standard

A launch image or clip passes only when a child or parent can explain what is happening without a caption, the creature is easy to see, the scene has a strong visual focus, and the moment creates a reason to play. Technical presence is necessary, but it is not visual quality.
