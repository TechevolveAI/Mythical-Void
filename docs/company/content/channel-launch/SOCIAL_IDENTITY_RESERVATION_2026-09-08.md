# One clear Mythical Void identity

**Status:** the naming plan is ready. No account has been opened, claimed or
changed, and nothing has been posted.

## The decision

Keep the public name **Mythical Void**. Try **PlayMythicalVoid** first wherever
a platform asks for a handle. If that cannot be claimed, use
**MythicalVoidGame**.

The exact `MythicalVoid` handle is already used by unrelated people on
YouTube, Instagram and TikTok. An unrelated Discord community also uses the
name. We should not contact those people, copy their identity or imply those
accounts belong to the game.

A public page failing to load does not prove a handle is available. Kevin must
check the name inside each platform when creating the account.

## Best order

1. Use Kevin's existing LinkedIn profile for the first founder story. This
   needs no new account or second email subscription.
2. If a separate studio page is wanted, try
   `linkedin.com/company/play-mythical-void`, then
   `linkedin.com/company/mythical-void-game`.
3. Reserve `@PlayMythicalVoid` on YouTube using a Google Account Kevin already
   controls. Do not publish videos until four real gameplay moments pass human
   review.
4. Reserve the same name on Instagram and TikTok only if recovery, two-step
   security and human reply cover are ready.
5. Leave Discord until the studio can safely moderate a community that may
   include children.

## Kevin's part

- Approve **PlayMythicalVoid** as the first handle to try.
- Check and claim it inside the chosen platform; accept any terms personally.
- Turn on two-step security and name a trusted adult backup.
- Keep passwords and recovery details outside Codex and the repository.
- Send back only the finished public address. The website should link to it
  only after ownership is confirmed.

Nothing in this plan authorizes account creation, posting, automated replies,
advertising or contact with children. It also forbids invented followers,
reactions, players or popularity.

Public wording stays simple: creatures, messages, clues, currents and routes.
Generated artwork must be labelled and never shown as gameplay. NASA does not
endorse Mythical Void.
