# Get Mythical Void onto YouTube and LinkedIn

Everything that can be prepared without account access is ready. You only need to create the two official pages and return their links.

## YouTube — about ten minutes

1. Sign in with the Google account that should own Mythical Void.
2. Create a channel using a **business or other name** and call it **Mythical Void**.
3. Try these handles in order: `@MythicalVoid`, `@PlayMythicalVoid`, `@MythicalVoidGame`. Their availability has not been checked.
4. Review and upload the finished profile image and 2560 × 1440 banner from [`YOUTUBE_CHANNEL_HANDOFF.md`](YOUTUBE_CHANNEL_HANDOFF.md).
5. Paste the prepared description from [`channel-activation-pack.json`](channel-activation-pack.json).
6. Add the Play, Story, and Press links in that order.
7. Choose **Review this setting for every video** for the audience setting. This matters because future videos may speak to different groups.
8. Keep comments **off** for now. Once a named adult is checking them, change the default to **Hold all**.
9. Turn on multi-factor authentication. Add a backup adult with a channel role instead of sharing the Google password.
10. Send back the exact channel link. Nothing will be published automatically.

## LinkedIn — about ten minutes

1. From Kevin’s real LinkedIn profile, choose **For Business → Create a Company Page → Company**.
2. Call the page **Mythical Void** and try `mythical-void` as the public address. If it is unavailable, try `play-mythical-void`.
3. Use **Computer Games** as the industry and the smallest truthful company-size option.
4. Paste the prepared tagline and About section from [`channel-activation-pack.json`](channel-activation-pack.json).
5. Turn on multi-factor authentication. Kevin remains the first super admin; add future helpers using LinkedIn roles, never a shared password.
6. Send back the exact page link. Five finished visual posts, captions, alt text and disclosures are ready but remain unpublished.

LinkedIn says a Company Page is free. Creating these pages does not require another Google Workspace subscription: YouTube can use an existing Google account, and LinkedIn uses Kevin’s existing personal profile to create the separate company page.
