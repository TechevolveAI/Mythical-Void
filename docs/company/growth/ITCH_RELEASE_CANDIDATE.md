# Mythical Void — itch.io release candidate

Status: technically packaged; publication and visuals still waiting

## What now exists

`npm run package:itch` creates a separate direct-play HTML game package at:

`release/mythical-void-itch-html5.zip`

It opens the game immediately, uses local file paths that work inside an itch.io project folder, keeps progress in the player’s browser and does not run the Mythical Void website’s Google tag. The normal mythicalvoid.com build is unchanged.

The package is automatically stopped if it exceeds itch.io’s current limits of 1,000 extracted files, 500 MB extracted size or 240 characters in a file path. It also checks that every local game file it names is present.

**Title:** Mythical Void

**Short description:** Hatch a strange alien creature, restore six living realms and decide what Project Beacon should tell Earth.

**Opening:** Crash beyond mapped space. Discover what survived. Mythical Void is a free browser adventure with no download or account needed.

**Full description:**

Wanderer-77 has crashed beyond mapped space. Recover the field kit, follow a
strange signal and hatch an alien creature shaped by genetics, cosmic affinity
and rare changes.

Together, cross six living realms, release their guardians from the Void,
build a sanctuary and decide what Project Beacon should tell Earth.

Mythical Void is a free, single-player browser adventure in early access.
Generative AI is part of the small studio's creative process and some optional
expressive features; people remain responsible for the story, safety, public
claims and important choices. Selected public NASA material may appear in
optional learning moments with its source shown. NASA does not endorse
Mythical Void.

**What players do:**

- hatch a creature shaped by body, colour, nature, affinity and mutations;
- run, leap, explore and fight through six living realms;
- free guardians from the corruption rather than simply destroying them;
- build a sanctuary and decide what Project Beacon should tell Earth.

**Controls:** WASD or arrow keys to move. Space to interact. Touch controls appear on supported smaller screens. Other controls are introduced inside the game.

**Suggested classification to confirm in itch.io:** HTML game; Adventure;
Phaser. Suggested tags: Adventure, Aliens, Creatures, Exploration, Family
Friendly, Platformer, Science Fiction, Story Rich and Singleplayer. Every tag
must still be checked against the platform's live choices before the page is
saved.

**Price:** Free. Do not ask for donations in the first release.

**Display:** Click to launch in fullscreen. Keep scrollbars off. Mark “Mobile Friendly” only after the uploaded package passes a real phone test on itch.io.

## Honest release boundary

This first portal package focuses on the main creature adventure. Optional hosted AI portraits and AI-made videos rely on Mythical Void’s own protected services and are not promised inside a third-party portal build. Live NASA material is an optional extra and cannot be guaranteed.

The father-and-son beginning and careful use of AI belong on the project page, but the first screen must sell the playable game.
