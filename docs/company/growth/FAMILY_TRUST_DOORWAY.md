# The family trust doorway

Status: live and production-verified
Routes: `https://mythicalvoid.com/playable-now/` and `https://mythicalvoid.com/parents/`

## Why this matters

An adult deciding whether a younger player should begin needs a few answers
before studio history or technology details. The current release is free to
start, contains no paid adverts, creates no public player profile and offers no
chat with other players.

Those points now appear beside the Play decision instead of being left for an
adult to infer from a long privacy page.

The words deliberately say **“no chat with other players.”** Mythical Void does
let a player talk to their creature through written game responses. Calling the
whole game “no chat” would be confusing.

## Evidence checked

- no common advertising SDK, host or package is present in the current web
  release sources;
- website analytics remain optional, outside the game and configured without
  advertising features;
- the current game is single-player;
- there is no public player profile or person-to-person chat route;
- the public claim registry limits both promises to the current release.

## Release boundary

Before adding adverts, multiplayer, public profiles or person-to-person chat,
the public promise must be removed or changed in the same release. Creature
dialogue must never be represented as another human player.

This change does not claim a formal age rating, universal suitability or that
no data is ever processed. It does not authorize advertising, outside posting,
platform submission or contact with a child.
