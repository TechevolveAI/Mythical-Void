# Mythical website ownership

The company work owns the public Mythical Void website. This includes everything a visitor sees before choosing **Play Now**.

## This company work owns

- The home page and public story
- The look and feel of the public website
- Clear information for children, teenagers, parents, and guardians
- Search descriptions and social sharing images
- Public safety, privacy, support, and contact information
- Learning what helps visitors understand the game and choose whether to play
- Making sure every Play Now button points to `/play/`
- Checking the public page on phone and desktop before each shop-window release
- Keeping public promises honest: no channel, feature, or support route is shown
  as live until it has been created and tested

## The Game Development work owns

- Everything that begins after a visitor chooses **Play Now**
- The game at `/play/` and `/game/`
- Game scenes, controls, saves, companions, battles, and progress
- The loading and error experience once the game is starting

## Shared rule

The handoff is the Play Now link. The public website may explain what happens in the game, but it must not change the game itself. If the game team changes the starting address or what players should expect, both sides must update the handoff together.

The company side is allowed to improve the explanation, pictures, layout, and
discovery of the game without waiting for a new game feature. It must use the
game team's verified facts when it describes genetics, Phaser, AI media, NASA,
or the story.
