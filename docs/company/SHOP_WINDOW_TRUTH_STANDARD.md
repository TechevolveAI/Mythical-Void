# Shop-window truth standard

The public Mythical Void website is the company’s shop window. It must show the game that exists, not a prettier invented version of it.

Before publishing a homepage change, the truth check must confirm:

- the page uses real assets from `public/game/` for gameplay, locations, guardians, and mission moments;
- generated marketing portraits are not presented as gameplay evidence;
- the words `Wanderer-77`, `Project Beacon`, `The Fend`, restoration, and player choice remain grounded in the game story;
- old or abandoned homepage language is removed from the source, not merely hidden by CSS.

The check is deliberately simple and can run without a network connection. A failed check means the shop window needs a human review before release.
