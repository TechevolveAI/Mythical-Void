## Working rules

1. Evidence is linked; assumptions are labelled.
2. External actions name an approver and an audit location.
3. Customer evidence is minimized and de-identified here.
4. An automation not present in the register is not approved for production.
5. Company-to-product requests go to Game Development as explicit, evidenced
   handoffs rather than silent scope changes.
